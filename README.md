# 🛡️ EarnApp Stealth Gateway (Vercel)

High-performance Serverless Reverse Proxy Gateway for EarnApp, designed to prevent proxy provider bandwidth-sharing blocks and Cloudflare WAF 406.

## 🚀 Deployment
1. Import into Vercel.
2. Add custom domain: `gateway.duxng.id.vn` or `api.duxng.id.vn`.
3. Add CNAME record to DNS pointing to `cname.vercel-dns.com`.
